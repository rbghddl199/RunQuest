RunQuest01. 프로젝트 소개01 / 04

AI 기반 맞춤형 러닝 코스 추천 서비스

RunQuest는 사용자의 취향과 러닝 기록을 분석하여 개인에게 적합한 산책 및 러닝 코스를 추천하는 서비스입니다. 사용자의 운동 경험과 활동 기록을 기반으로 맞춤형 코스를 추천하고, GPS 기록 측정과 커뮤니티 기능을 통해 지속적인 운동을 지원합니다.

기존 러닝 서비스의 한계
문제 1

사용자 개개인의 운동 능력과 활동 이력을 충분히 반영하지 못하는 경우가 있습니다.

문제 2

특히 초보자와 장기간 운동을 중단한 복귀 사용자에게는 동일한 추천 기준을 적용하기 어렵습니다.

기획

사용자 상태에 따라 추천 기준을 차별화하는 개인 맞춤형 러닝 서비스를 기획했습니다.
