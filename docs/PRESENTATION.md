# RunQuest 시연 가이드

## 핵심 문장

RunQuest는 사용자의 설문, 러닝 기록, 현재 위치를 바탕으로 오늘 달리기 좋은 대전 러닝 코스를 추천하고, 러닝 기록을 커뮤니티와 연결하는 AI 기반 러닝 추천 서비스입니다.

## 해결하려는 문제

- 초보자는 어디서 얼마나 달려야 할지 결정하기 어렵습니다.
- 기존 러닝 앱은 기록 저장은 강하지만 다음 코스 추천은 약한 경우가 많습니다.
- 날씨, 위치, 컨디션, 과거 기록이 따로 흩어져 있어 사용자가 직접 판단해야 합니다.
- 러닝 후 기록을 공유하거나 코스로 재사용하는 흐름이 불편합니다.

## RunQuest의 해결 방식

1. 설문 기반으로 신규 사용자의 취향을 파악합니다.
2. 러닝 기록이 쌓이면 실제 거리, 페이스, 코스 유형을 추천에 반영합니다.
3. 위치 권한이 있으면 가까운 코스를 우선 추천합니다.
4. GPS 또는 시뮬레이션 모드로 러닝을 기록합니다.
5. 자유 러닝 완료 후 직접 만든 코스로 저장할 수 있습니다.
6. 커뮤니티에서 코스와 러닝 기록을 연결해 공유합니다.
7. 챗봇이 현재 상태에 맞는 코스를 대화형으로 추천합니다.

## 추천 알고리즘 설명

추천은 설명 가능한 점수 기반 방식입니다.

| 사용자 상태 | 추천 기준 |
| --- | --- |
| 신규 사용자 | 설문 결과 중심 |
| 기존 사용자 | 설문 + 최근 러닝 기록 |
| 복귀 사용자 | 설문 + 과거 기록 + 안전 보정 |
| 위치 제공 사용자 | 코스 시작점과의 거리 우선 반영 |

생성형 AI는 최종 랭킹 자체를 전적으로 결정하지 않습니다. 코스 추천 이유, 챗봇 응답, 러닝 피드백 문구를 자연스럽게 만드는 보조 역할을 합니다.

## 시연 계정

fixture 로드 후 아래 계정을 사용할 수 있습니다.

| 계정 | 용도 |
| --- | --- |
| `new@runquest.com` | 신규 사용자 추천 흐름 |
| `runner@runquest.com` | 기존 사용자 기록 기반 추천 |
| `comeback@runquest.com` | 복귀 사용자 안전 보정 추천 |

공통 비밀번호는 `!@1q2w3e4r`입니다.

## 권장 시연 순서

1. 홈 화면에서 오늘의 요약, 추천, 미션을 보여줍니다.
2. 추천 화면에서 추천 코스와 추천 이유를 설명합니다.
3. 챗봇에서 “오늘 가볍게 3km 정도 뛰고 싶어” 같은 문장을 입력해 대화형 추천을 보여줍니다.
4. 코스 상세 또는 러닝 시작 화면에서 Kakao Map 경로를 보여줍니다.
5. 시뮬레이션 모드로 러닝을 시작해 거리, 시간, 페이스가 자연스럽게 증가하는지 보여줍니다.
6. 러닝 완료 페이지에서 지도, 기록, 피드백을 확인합니다.
7. 자유 러닝 기록을 내 코스로 저장할 수 있음을 설명합니다.
8. 내 코스 화면에서 북마크, 직접 생성, GPX 코스가 분류되는 흐름을 보여줍니다.
9. 커뮤니티에서 게시글, 댓글, 좋아요, 저장, 관련 코스/기록 연결을 보여줍니다.
10. 마이페이지에서 출석, 배지, 누적 기록을 보여줍니다.

## 강조할 기술 포인트

- Django REST Framework 기반 REST API
- JWT 인증과 사용자 설정 관리
- GPX 파싱을 통한 실제 코스 좌표 반영
- GPS와 시뮬레이션 러닝 모드 분리
- 자유 러닝 완료 후 사용자 코스 저장
- 커뮤니티 목록 API 쿼리 최적화
- 요청/메서드 단위 성능 로그
- Kakao Map 기반 경로 시각화
- LLM/OpenAI 선택 연동과 로컬 fallback

## 한계와 향후 개선

- 실제 모바일 GPS 장시간 검증이 더 필요합니다.
- 운영 환경에서는 SQLite 대신 PostgreSQL 전환이 필요합니다.
- 커뮤니티 이미지는 base64 JSON 대신 media URL 또는 S3 방식으로 개선할 수 있습니다.
- 추천 알고리즘은 사용자 행동 로그가 쌓이면 협업 필터링이나 임베딩 기반 추천으로 확장할 수 있습니다.
